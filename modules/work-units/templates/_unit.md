**Depends on:** links to the units this one needs, or "nothing". Say when an
edge is an *ordering preference* rather than a hard dependency — a soft edge
presented as a hard one hides a scheduling choice.
**Discharges:** the scope row, known limitation, or documented promise this
closes. If it closes none, say so rather than inventing one.

One or two sentences on what this is and why it sits here. Not a restatement of
the title.

## Done means

Verifiable claims: things a skeptical reviewer can check, not intentions. Each
bullet should be falsifiable.

- Prefer "asserted by &lt;the thing that asserts it&gt;" over "is correct".
- Name the file or the check where one already exists.
- If a number is claimed, say where it was measured.
- If something is deliberately *not* done, say that here rather than leaving its
  absence to be discovered.

## Risks

What could go wrong, or what is genuinely unknown until the work starts. "Low"
is an acceptable answer; an empty section is not, because it reads as "not
considered" rather than "considered and small".
