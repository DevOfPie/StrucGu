# Work

the decision log states **why**. Rationale here and status there are both wrong.

One file per unit of work. **Read exactly the one you are building** — that is
what this split is for. Nothing here restates another file.

**Status lives here, and only here.** If another document also tracks status,
one of them is wrong and nobody can tell which.
