# Decisions

Why things are the way they are. Name the document that states *what* is true;
this file states *why*. Rationale there and status here are both wrong.

Entries are append-only and dated. A later entry may correct an earlier one; the
earlier text is left in place with a pointer rather than edited away, because
deleting it destroys the record that the earlier belief was ever held.

Headings are claims — things that can be true or false. "Caching" is a topic;
"Cache lifetime is clamped to the link's expiry" is a claim. Topics accumulate
and can never be contradicted, which disables the correction mechanism this file
depends on.
