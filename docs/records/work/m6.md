# M6 — Fixtures, and every check observed failing

**Depends on:** [M3](m3.md), [M4](m4.md).
**Discharges:** the README's claim that fixtures are the evidence, and the
promise that a consumer can verify their own checker.

With no runner shipping, fixtures do two jobs at once: they are the only proof a
check detects anything, and they are the conformance suite an implementer tests
their checker against. Both jobs fail if a fixture is written to match a check
that was never watched failing.

## Done means

- Every check in all five modules has a `violates-<CHECK-ID>/` tree and the
  module has a `satisfies/` tree.
- Each module's `fixtures/expected.md` names, per fixture, the exact finding a
  correct checker produces — and states that the satisfying tree produces none.
- At least two fixtures are modelled on drift observed in LinkCtrl rather than
  invented: a triage document pointing at a destination that has moved, and two
  documents each claiming to be the sole home of status. Their provenance is
  stated in the fixture or in [decisions.md](../decisions.md).
- Fixtures contain no language, package manager, build tool, or file extension
  beyond markdown and the adoption record.
- Each fixture tree is minimal — it violates one check and satisfies everything
  else it can, so a checker's output on it is unambiguous.
- The list of checks **cut** for having no meaningful violating fixture is
  recorded in [decisions.md](../decisions.md). This list is the most valuable
  output of this work unit; an empty list is a signal the criterion was not
  applied rather than that every check survived.
- Deliberately not done: no fixture exercises a check across a repository with
  real history, so `history_deletions` is covered only by its stated meaning and
  its `effective_from` requirement, not by an observed run. Recorded rather than
  papered over.

## Risks

A fixture written by the same person who wrote the check tests the check against
its author's understanding of it, which is exactly the understanding that is
already encoded. This is the weakest link in the evidence chain and there is no
fix available inside this repository — the real test is the first independent
checker, and the fixtures' job is to make that test possible rather than to be
it.
