# M7 — StrucGu adopts, and 0.1.0 is tagged

**Depends on:** [M5](m5.md), [M6](m6.md).
**Discharges:** the README's statement that StrucGu keeps its own records and
maps them in its own adoption record, and the repository having no released
version.

The last unit is the one that exercises the escape hatches, because that is
where every adopter will spend their time and the part most likely to be badly
designed.

## Done means

- [strucgu.yaml](../../../strucgu.yaml) exists at the repository root and maps
  StrucGu's own roles to paths under [docs/records/](../).
- It exercises the `skip` path with at least one deliberately unmapped role, and
  states in a comment why that role is unmapped rather than leaving it blank.
- **It carries no deviation, and that is stated rather than left as an absence.**
  This work unit originally required one, so that the shape would be tested by
  use rather than only specified. No genuine deviation exists — every check
  StrucGu adopts, it passes — and writing a false one into the repository's own
  adoption record to exercise a mechanism would be a lie in the one file whose
  entire purpose is to be a truthful claim. The shape is instead worked through
  in [SPEC.md](../../../SPEC.md), [adopting.md](../../adopting.md), and
  [objections.md](../../objections.md), and remains untested by use until a real
  one arrives.
- Every check in all five modules has been walked against this repository by
  hand, and the walk's output is committed under [docs/records/](../) so a later
  reader can diff against it rather than take the claim on trust.
- The walk produces either no findings, or only findings already recorded as
  rows in [findings.md](../findings.md) with evidence and an unreviewed state.
- Every relative link and anchor in every tracked markdown file resolves.
- No banned word is used as a repository-level status. The words do appear, in
  [SPEC.md](../../../SPEC.md) and [triage.md](../triage.md), in the rules that
  define the ban — a rule that cannot name what it forbids is not a rule.
- Nothing under `modules/` names a language, package manager, build tool, or
  file extension.
- [CHANGELOG.md](../../../CHANGELOG.md) states what shipped and what it does not
  do.
- All five modules are at `0.1.0`; each module changelog states what a
  previously clean adopter will newly see, and for a first release states
  "nothing" rather than omitting the sentence.
- Deliberately not done: the repository is not tagged by this work unit. Tagging
  is the owner's action, and a work unit that tags on the owner's behalf is the
  same category error as an audit that files an issue on a consumer's behalf.

## Risks

The self-walk is performed by the same party that wrote the checks, by hand,
with no implementation to disagree with them. It will therefore find close to
nothing, which is the expected outcome and is why
[decisions.md](../decisions.md#self-application-is-dogfooding-not-evidence)
refuses to offer it as evidence. The failure mode to watch for is the walk being
read as validation by someone who skipped that entry — the committed output
should say what it is worth on its face.
