# M13 — The catalog says what a year of one repository could not

**Depends on:** [M9](m9.md), [M10](m10.md), [M11](m11.md), [M12](m12.md). The
edge to [M9](m9.md) exists because nothing else depended on it, which made its
deferral indistinguishable from a silent cut — it resolves here as written or as
cut on the record, and either satisfies this edge.
**Discharges:** the [README.md](../../../README.md) statement of what 0.x means
here, which after this phase can be replaced with findings rather than a
disclaimer.

Phase one shipped a catalog and said honestly that it was extracted from one
repository and implemented by nobody. This unit is where the version number
stops being a promise about future evidence and starts summarising evidence that
exists.

## Done means

- Every module changelog states, in the fixed sentence, what a previously clean
  adopter will newly see — including the modules where the answer is "nothing",
  written out rather than omitted.
- The release is walked per [triage.md](../triage.md) "Before a release is
  tagged": every gate over the whole repository, a hand walk of every check, and
  a repeat from step one if the walk triggers work.
- The self-walk is re-run and **committed as a second file rather than by
  overwriting [self-walk.md](../self-walk.md)**. The diff between two walks is
  the first thing in this repository that shows movement, and overwriting
  destroys it.
- The walk includes the `IN-*` checks reporting `ok` or `finding` rather than
  `skip`, because [M10](m10.md) mapped the `investigations` role to a real
  investigation.
- **It records what that costs.** Those four skips were the only exercise of the
  `skip` path and the conditional obligation anywhere in this repository — see
  [self-walk.md](../self-walk.md) and the comment in
  [strucgu.yaml](../../../strucgu.yaml). The second walk exercises `skip`
  nowhere, and the walk says so rather than reporting a cleaner-looking summary
  as an improvement. Coverage of that path remains only in the fixture trees.
- **It records [M11](m11.md)'s deviation from the verifiability gate at the
  gate.** [triage.md](../triage.md) requires every documented claim to be
  verifiable by a reader who does not trust you, and [M11](m11.md)'s redacted
  audit of a private repository is not. The release walk names it as a knowing
  deviation with a pointer to where it is argued, rather than passing over it.
- If [M9](m9.md) was cut rather than written, the release states that the
  catalog ships with no stated pass criterion, and why.
- [README.md](../../../README.md) "What 0.x means here" is rewritten against
  what actually happened: how many ambiguities the first implementation found
  and how many of those it resolved at low confidence, what the second adopter's
  audit reported, and whether any objection changed a module. If the answer to
  the last is no, it says no.
- **It does not claim generality.** [M11](m11.md) tested re-application inside
  one convention lineage and [M10](m10.md)'s implementer shares a lineage with
  phase one's co-author. Both limits are stated where the results are, not
  buried in the work records that admit them.
- The version bump is justified by the rule rather than by the size of the
  phase — MAJOR if any check was added or any obligation's shape changed, MINOR
  otherwise, per [SPEC.md](../../../SPEC.md) "Versioning". A phase this large
  ending in a minor bump is a legitimate outcome and the changelog should not
  apologise for it.
- Deliberately not done: the repository is not tagged by this work unit, for the
  reason [M7](m7.md) already gives — tagging is the owner's action.

## Risks

The version number will be argued about, because MAJOR here would be driven by
whichever way [M12](m12.md) resolved `F2` rather than by the weight of the phase,
and that reads backwards to anyone who did not follow the reasoning. The
changelog is where that gets explained, once.

The larger risk is that this phase produces enough evidence to be *read* as
maturity. One implementation and one second adopter is exactly two data points,
both from parties adjacent to the author — one sharing a model lineage with
phase one's co-author, the other sharing a convention lineage with the
repository the catalog was extracted from. It is a great deal more than phase
one had and it is not a track record, and the rewritten 0.x section is the place
that has to keep saying so.
