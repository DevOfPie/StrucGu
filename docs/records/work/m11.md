# M11 — A second repository adopts, and the objection channel is used in anger

**Depends on:** [M10](m10.md) — an adoption with nothing to run against produces
opinions rather than findings.
**Discharges:** the [README.md](../../../README.md) statement that "one instance
is not enough to know which conventions are general and which are one project's
habits wearing a rule's clothing", which is currently a label on the version
number rather than a thing anyone has acted on.

The catalog was extracted from one repository. Four of the seven phase-one work
records name that as their risk, in different words. It cannot be answered from
inside this repository at any effort.

## Done means

- A repository that is **not** the one the catalog was extracted from, and not
  this one, carries a real hand-edited `strucgu.yaml` mapping its own paths.
- [M10](m10.md)'s checker is run against it and the output is recorded.
- Every finding is disposed of as exactly one of: fixed, waived with a reason in
  that repository's own adoption record, or filed as an objection carrying the
  six required fields in [objections.md](../../objections.md).
- **At least one objection is filed, or the absence of one is recorded as a
  finding about this unit.** A second repository that produces no disagreement
  was either chosen too close to the first or audited without conviction, and
  saying so is worth more than a clean result.
- Any objection is disposed of through the four outcomes in
  [objections.md](../../objections.md) and lands as a dated entry in
  [decisions.md](../decisions.md), including a decline.
- The record states who wrote the second repository. If it is the same author,
  that is the dogfood problem in a new costume and the result is worth
  proportionally less — stated on its face, in the same terms
  [self-walk.md](../self-walk.md) uses about itself.
- Deliberately not done: no attempt to recruit an outside adopter. That is not a
  work unit, it has no falsifiable done condition, and a catalog that measures
  itself by adopters has started counting the thing it refused to count.

## Risks

The candidate repositories available are all the same author's, so the strongest
version of this test is not reachable today. What *is* reachable is a repository
with different subject matter, a different record shape, and history that
predates the catalog — which tests whether the roles map onto a structure that
was not built to receive them. That is a genuine test of generality even when the
author is shared, and it is a weaker one, and both halves belong in the record.

The second risk is that the audit is performed to pass. An author auditing their
own second repository with their own checker against their own spec has three
chances to unconsciously look away. The mitigation is disposing of findings by
the rule rather than by judgment — every finding gets fixed, waived in writing,
or argued in an objection, and "not really a problem" is not one of the three.

A private repository adopting brings the exfiltration surface
[objections.md](../../objections.md) already names: audit output carries paths,
internal names, and quoted lines. Any objection filed from it is written by hand
and reviewed before it leaves, which is the rule that document already states
and this unit is the first occasion to actually follow it.
