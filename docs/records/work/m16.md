# M16 — Every stated behaviour has a tree, or the statement is cut

**Depends on:** [M15](m15.md), hard. This unit rewrites expectation rows in bulk,
which is the change class M15 exists to size.
**Discharges:** the *What a conformance claim cannot cover* table in
[conformance.md](../../conformance.md), which is the closest thing this repository
has to a list of its own untested assertions.

[triage.md](../triage.md) already says a check no tree can violate is measuring
nothing and gets cut, and that the list of what was cut is worth more than the
checks that survived. That rule governs **checks**. Nothing governs normative
prose, so [SPEC.md](../../../SPEC.md) states a dozen behaviours a checker must
have and tests none of them — *"a checker can get all three wrong and reproduce
every row"* is this repository's own sentence about three of them.

## Done means

- **The rule is written down and applied in the same unit.** A normative statement
  about what a checker does is either pinned by a tree or cut, and a statement
  that can be pinned by no tree says so where it is made. **The rule is written in
  [triage.md](../triage.md); the list of statements that survive with no tree is
  written in [SPEC.md](../../../SPEC.md).**
  *Amended 2026-08-04 — this bullet claimed the decision for the unit while
  [README.md](README.md) reserved it for the owner, which
  [triage.md](../triage.md) makes a bug to report rather than a choice to take. It
  was reported, the owner answered, and the before, after and reasoning are in
  [decisions.md](../decisions.md#the-cut-rule-is-this-repositorys-practice-the-list-it-produces-is-the-catalogs).*
- **`waived` is exercised by a fixture.** No tree carries a `deviations` block, so
  one of the [five states](../../../SPEC.md#audit-output) is demonstrated nowhere
  in the catalog; the only `waived` in existence came from a second repository. A
  tree carries a deviation with a reason and an expiry, and `expected.yaml` pins
  the resulting state.
- **The git behaviours are pinned or declared unpinnable.** That `path_exists`
  requires a **tracked** path inside a repository, that history is read from the
  audited root and never by walking up, and that `effective_from` is exclusive and
  compared by committer date. Exactly one tree in the catalog is a repository, and
  only via a `SETUP.md` block — so the cost of pinning these is that fixture
  construction stops being a matter of copying files, and the unit states that
  cost rather than absorbing it.
- **`dir` roles and subdirectories are pinned in both directions.** No fixture tree
  has a subdirectory today, so whether a `dir` role reaches into one is
  undetermined either way.
- **The three link cases are pinned or cut:** a link to a directory, an anchor on a
  non-markdown file, and the `-1` suffix on a duplicate heading. Each is decided in
  the specification and tested by nothing.
- **Every statement that survives without a tree is listed**, in the specification
  and not only in a record, with why no tree can reach it. That list is the unit's
  most valuable output and it is expected to be non-empty.
- No new check is added, and no obligation's shape changes. If pinning a behaviour
  turns out to require either, the unit stops and asks rather than growing the
  catalog inside a unit about measurement.

## Risks

**The count is unknown until the work starts, and that is the honest number.**
Every tree added is a tree every implementer must reproduce forever, so this unit
can quietly make the catalog more expensive to implement than it is to adopt. A
ceiling stated in advance would be arbitrary; what the unit owes instead is a
running count and a statement of what each tree buys.

The sharper risk is that a tree written to pin a behaviour ends up asserting the
reference implementation's reading of it. Five of nine deliberate breakages once
produced a clean run here, and the fixtures added afterwards were written by the
same party that wrote the implementation. A tree that pins what
[strucgu-check](https://github.com/DevOfPie/strucgu-check) happens to do is not a
specification; [M18](m18.md) is where that gets tested rather than assumed.
