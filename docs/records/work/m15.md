# M15 — Four records stop asserting what is no longer true

**Depends on:** [M14](m14.md), as an *ordering preference* rather than a
dependency of substance — both are corrections and doing the mechanical one first
keeps the two kinds of judgment apart.
**Discharges:** `F3`, `F15`, `F17` and `F19` in [findings.md](../findings.md).

Four documents state things that were true when written and are not true now.
None is a defect in a check; all four are the failure mode this catalog exists to
name, which is a record that reads as maintained because nothing mechanical
disagrees with it.

## Done means

- **`F3`** — `triage-rule`'s `expected.md` states a judgment-line count matching
  no reading of its own fixtures. The prose file agrees with
  [expected.yaml](../../../modules/triage-rule/fixtures/expected.yaml), or states
  why it counts differently. `expected.yaml` is not edited to match the prose: the
  conformance criterion is measured against the data file, and moving the measured
  side to fit an unmeasured one inverts which file is authoritative.
- **`F15`** — [auditing.md](../../auditing.md) lists a module's `fixtures/`
  directory without `expected.yaml`, which [SPEC.md](../../../SPEC.md) has
  required since [M8](m8.md). The listing is complete, and the sentence that sends
  an implementer to the prose file sends them to the data file instead.
- **`F17`** — the [decisions.md](../decisions.md) index is one row short of the
  file's entries. The missing row is added. No entry is edited, and the unit
  states the count before and after so the fix is verifiable.
- **`F19`** — [README.md](README.md) opens by saying M8–M13 are scoped and
  unstarted, and that `planned` and `deferred` are words its table has not used.
  The paragraph describes the phase it belongs to, in the past tense, or is cut
  with the cut recorded.
- **The reopening question is answered on the record, not in advance.** `F3` and
  `F15` both trace to [M8](m8.md) — one is its prose half left behind, the other
  is the adopter-facing guide it did not update. Whether that makes M8's claim
  false, and therefore [reopens it](../triage.md), or whether M8's claim stands
  and these are corrections beside it, is this unit's judgment to make and to
  argue in [decisions.md](../decisions.md). `F17` and `F19` are not reopenings:
  no unit ever claimed a complete index, and the stale paragraph belongs to the
  phase plan rather than to any unit's definition of done.
- Every row moves to *Closed* with its disposition. Nothing is closed by being
  deleted.

## Risks

The reopening judgment is the risk, and it is a rule being used for the first
time. Reopening too readily makes the status table churn and turns every prose
defect into a unit that was never finished; reopening too reluctantly leaves
`done` rows asserting things this repository has already written down as false,
which is the outcome the rule was added to prevent. The unit has to pick, and the
argument it records is worth more than the pick.

`F3` carries a smaller trap. The count in the prose file is wrong, and the
temptation is to make the number agree without asking which reading it was ever
counting — six, two, or four. A number changed to end a disagreement is the same
class of defect as the one being closed.
