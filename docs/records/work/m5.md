# M5 — Adoption and the objection loop

**Depends on:** [M3](m3.md), [M4](m4.md).
**Discharges:** the README promising a one-file adoption and an objection
channel, with nothing documenting either.

The catalog is worthless if adopting it is harder than rebuilding the
conventions by hand, and it cannot improve if the repositories using it have no
way to say it is wrong.

## Done means

- [docs/adopting.md](../../adopting.md) walks two paths — a new repository and
  one with years of history — and both end at exactly one file added, with zero
  changes to build tooling, CI, or any dependency manifest.
- It names the collisions honestly rather than leaving them to be discovered:
  commit-message conventions that reject prose, a docs directory published to
  the web taking the findings queue with it, tooling that rewrites decision
  records in place, and an existing contributing guide that must not be
  replaced.
- Every named collision has an escape hatch stated next to it.
- It documents partial adoption, unmapped roles, exclusions, and the fact that
  a repository may use a template without adopting anything.
- [docs/auditing.md](../../auditing.md) documents the five output states, what
  a checker must do to be correct, and why the recommended default is not a
  gate.
- It documents every remediation prohibition, including the append-only
  exception and its worked precedent.
- [docs/objections.md](../../objections.md) defines the required fields,
  including what complying would cost, and states that an objection with no cost
  is a preference.
- It defines the four outcomes and which version bump each produces, and states
  that every outcome lands as a decision entry.
- It states that a checker may draft an objection and a person files it, with
  the reason.
- The deviation record shape is specified with `reason` and `review_by` both
  required, and states what an expiry is for.

## Risks

The adoption story is untested — no repository other than this one has adopted
anything, so the claim that it costs one file is an argument rather than an
observation. The honest cost is also larger than one file for the first adopter,
because they must write a checker before any of it does anything, and the
adoption document has to say so without burying it.
